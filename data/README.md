## Dataset Information

This project uses a publicly available cervical cancer image dataset from Mendeley Data.

- Dataset name: Cervical Cancer (LBC Pap Smear Images)
- Total images: 963
- Classes:
  - Negative Intraepithelial Malignancy (NIM)
  - Low Squamous Intraepithelial Lesion (LSIL)
  - High Squamous Intraepithelial Lesion (HSIL)
  - Squamous Cell Carcinoma (SCC)

Dataset link:
https://data.mendeley.com/datasets/zddtpgzv63/4

The dataset is not included in this repository due to size and licensing constraints.
Please download it from the above link and place it inside the `data/` directory before running the notebook.
